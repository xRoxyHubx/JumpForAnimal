# RoxyHub - Jump for Animals!
An advanced, high-performance automation suite for the Roblox game "Jump for Animals!", built with the modern WindUI framework and optimized for both PC and Mobile executors.
---
## Overview
RoxyHub delivers complete automation, custom visual themes, fast progression loops, and a fully responsive interface tailored for both desktop and touch devices.
---
## Key Features
### 1. Auto Farm & Progression
- Auto Squat / Train: Automatically positions the character at squat training machines to farm Jump Power continuously.
- Auto Squat Bonus (2x Turbo): Automatically triggers and completes the mini-game bonus whenever prompted.
- Auto Upgrade Barbell: Continuously purchases the best available barbell upgrades.
- Fossil Event Live Tracker: Real-time countdown and automated monitoring for Meteor Shower and Research Table events.
### 2. Eggs & Pets Automation
- Auto Hatch: Automatic egg hatching with multi-egg support.
- Auto Place Eggs: Automatically places eggs onto plots, with options to filter by egg type.
- Auto Equip Best: Keeps the highest stat pets equipped at all times.
- Auto Sell & Manage: Automatically sells low-tier pets and upgrades pet storage slots.
### 3. Visuals & ESP
- Player ESP: Box highlights and billboards showing player distance and carried items.
- Carrier Highlight: Special visual indicator for players carrying items or eggs.
### 4. Player Utilities & Movement
- WalkSpeed & JumpPower modifiers with instant lock toggles.
- Infinite Jump and Noclip.
- CFrame Speed Multiplier for smooth, high-speed traversals.
- Bypass Carry Jump: Removes movement penalties while carrying objects.
- Instant Interact: Bypasses ProximityPrompt hold duration.
### 5. Profile & Configuration Management
- JSON-based configuration manager.
- Save, load, and delete custom user profiles directly to executor storage.
### 6. Mobile & Cross-Platform Support
- Draggable Floating Toggle Button: A circular RoxyHub floating icon enabled by default.
- Full Touch Support: Tap the floating button to open or close the menu; drag it anywhere on screen.
- Screen Bounds Clamping: Prevents the button from being dragged off-screen.
- PC Keybind: Press RightShift to toggle the interface.
